# sql-portfolio-analysis

## Overview
This repository contains SQL analytics projects completed using Google BigQuery public datasets. The following projects focus on blockchain analytics and healthcare operations.


# Project 1: Ethereum Blockchain Analytics

## Objective
Analyze Ethereum transaction behavior, wallet segmentation, and network fee trends.

## Tasks Completed
- Network Congestion & Fee Trends
- Whale Wallet Tier Segmentation
- Daily Top-Value Transfers
- Rolling Cost Forecast

## Key Findings
Task 1 – Network Congestion & Fee Trends
- Daily transaction activity changed throughout the analysis period, showing different levels of network demand.
- Periods with heavier transaction volume also came with higher average gas prices.
- The data suggests that network congestion has a direct impact on transaction costs for users.

Task 2 – Whale Wallet Tier Segmentation
- Most active wallets fell into the Fish category, showing that smaller transactions dominate network participation.
- Whale wallets represented a much smaller group of addresses but were responsible for a significant share of the value transferred, and were mostly shown at the top.
- Transaction volume appeared to be concentrated among a relatively small number of high-value participants.

Task 3 – Daily Top-Value Transfers
- High-value transfers occurred consistently throughout the selected week.
- The largest transactions each day accounted for a big portion of total value movement on the network.
- The presence of recurring large transfers shows institutional or large-scale investor activity.

Task 4 – Rolling Cost Forecast
- The 7-day moving average smoothed short-term fluctuations in gas prices and revealed broader cost trends.
- Temporary spikes in gas prices were easier to identify when compared against the moving average baseline.


# Project 2: Healthcare Analytics

## Objective
Analyze healthcare pricing patterns and identify unusual cost behavior.

## Tasks Completed
- Hospital Cost Markup Analysis
- Geographic Price Variance
- Statistical Outlier Detection
- Cross-Domain Analysis

## Key Findings
Task 1 – Hospital Cost Markup Analysis
- Significant differences were observed between covered charges and actual payments received by hospitals.
- Some providers maintained substantially higher markup ratios than others.
- The results highlight notable variation in hospital pricing practices across the healthcare system.

Task 2 – Geographic Price Variance
- Average procedure costs varied considerably across states.
- Certain states consistently ranked among the highest-cost regions for multiple procedures.
- Geographic location appears to be an important factor influencing healthcare spending patterns.

Task 3 – Statistical Outlier Detection
- Only few providers charged significantly above the national average.
- These outliers stood apart from the majority of providers based on pricing behavior.

Task 4 – Cross-Domain Analysis
- Regional differences were observed in both hospital payments and drug costs.
- States with higher healthcare expenses often showed elevated costs across multiple healthcare services.
